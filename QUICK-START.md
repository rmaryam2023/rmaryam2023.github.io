# Quick Start Guide

## 🎯 What You Need to Do (5 Minutes)

### Step 1: Update Contact Info
Edit `index.html`:
1. Search for `your.email@example.com` → Replace with your email (appears twice)
2. Search for `yourusername` → Replace with your GitHub username (appears ~7 times)
3. Search for `yourprofile` → Replace with your LinkedIn profile name (appears 3 times)

### Step 2: Upload to GitHub Pages (Free Hosting)

1. **Create GitHub Account** (if you don't have one)
   - Go to https://github.com/join

2. **Create Repository**
   - Click `+` icon → "New repository"
   - Name it: `yourusername.github.io` (use YOUR actual username!)
   - Make it **Public**
   - Click "Create repository"

3. **Upload Your Files**
   - Click "uploading an existing file"
   - Drag these files:
     - index.html
     - contract-gap-analysis-case-study.html
     - style.css
     - script.js
   - Click "Commit changes"

4. **Enable GitHub Pages**
   - Go to Settings (in your repository)
   - Click "Pages" in sidebar
   - Under "Source", select "main" branch
   - Click Save

5. **Done!** Your site will be live at:
   ```
   https://yourusername.github.io
   ```
   (Takes 1-2 minutes to go live)

## 🆘 Need Help?

- GitHub Pages not working? Check that repo name is exactly `yourusername.github.io`
- Site not updating? Wait 2-3 minutes, then hard refresh (Ctrl+Shift+R / Cmd+Shift+R)
- Email showing weird? That's a security feature, it'll work when live
